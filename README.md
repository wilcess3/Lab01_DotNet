-Главные выводы
Про .NET: Это удобная «среда», в которой работают программы на C#. Она работает как переводчик: ваш код сначала превращается в специальный «секретный язык» (IL-код), а потом .NET запускает его на любом компьютере — хоть на Windows, хоть на Linux. Поэтому программы на C# такие универсальные

Про типы переменных:В C# нельзя просто так взять и поменять тип данных у переменной.Если вы сказали, что в ячейке будет целое число,то там всегда будет только целое число. Слово var — это просто маленькая хитрость:оно позволяет не писать тип вручную, но сам тип всё равно фиксируется навсегда. В Python так нельзя

Про Git: Git запоминает все изменения, которые мы вносим. А GitHub — это облако, куда мы отправляем свой проект, чтобы он не потерялся и чтобы его могли посмотреть другие

Ответы на вопросы:
1.Console.Write() выводит текст и оставляет курсор на той же строке — следующий текст напечатается сразу после. А Console.WriteLine() выводит текст и переносит курсор на новую строку, т.е следующий текст будет уже с новой строчки

2.Будет ошибка компиляции. Тип int может хранить только целые числа, а это дробное число. Для дробных чисел нужен тип double

3.Потому что оба числа — целые. Когда C# делит целое на целое, он отбрасывает дробную часть и оставляет только целую. Чтобы получить дробный результат, нужно чтобы хотя бы одно из чисел было дробным. Для этого просто пишут 10.0 / 3

4.var — это просто удобное сокращение. Вместо того чтобы каждый раз писать int x = 5; или string name = "Иван";, можно написать var x = 5; или var name = "Иван";. Компилятор сам посмотрит на значение справа и поймёт, какой тип поставить
 Отличие от Python: в Python тип переменной может меняться во время работы программы. В C# тип, который определил компилятор, фиксируется навсегда. Если var x = 5, то x навсегда останется целым числом, и записать туда строку уже не получится — будет ошибка
